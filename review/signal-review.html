Policy Window Monitor, Protocol v0.4

Review happens in two steps for each topic and stream. Step 1, concept checks: each card says how the topic is framed by one concept (for example, a focusing event, or a salient issue), why, and how strong the evidence is. Step 2, stream level: whether those concepts together are enough to drive the problem or the politics stream. Choose Approve if it is right, Change to set a different strength or level, or Reject if it should not count. Add a comment by typing or with the microphone. Everything saves as you go and the next weekly run reads it.
